# catalyst-refusal-watch

Делает видимым каждый обрыв ответа фильтром сервиса в момент обрыва и добавляет
модели правило: сообщить об остановке и не бросать линию работы молча.

Плагин не меняет поведение движка при обрыве и не трогает текст, который движок
вставляет модели. Отказов и `deny` нет — только видимость.

## Что делает

- `turn.step` отдаёт чанки и результат без изменений и в том же порядке. Если
  `stopReason` чанка `stop` или результата шага — `refusal`, показываются тост,
  статус сессии и строка транскрипта (модели она не уходит).
- `turn.complete` при `reason: "refusal"` (ход оборван и повтора не было)
  сообщает отдельно. Если шаг того же `turnId` уже сообщил об обрыве в последние
  60 с, тост всё равно есть, а счётчик сессии второй раз не растёт.
- `tool.call` инструмента `TaskStop` в окне 30 минут после обрыва показывает
  тост с id задачи. Вызов не блокируется и вне окна ничем не отмечается.
- `prompt.context` добавляет один блок `refusalHandling`. Повторный блок с тем
  же именем не создаётся: текст существующего заменяется.

Журнал пишется в `$.store` под ключом `log`, не длиннее 100 записей. Каждый
канал доставки изолирован: его отказ не прерывает шаг, ход или вызов.

## Зубы

```
CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude plugin test <путь к этому каталогу>
```

`tests/behavior.test.ts` — 11 тестов официального стенда: текст и счётчик
обрыва шага, тишина на `end_turn`, прозрачность чанков, категория хода без
повтора, окно `TaskStop`, единственность блока правила, отказ тоста, дедуп
счётчика за 60 с, обрезка журнала.

```
claude plugin validate <путь к этому каталогу>
```
